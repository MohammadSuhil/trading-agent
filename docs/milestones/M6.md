## Known traps
- Any soak-week failure restarts the 7-day clock; realistic is 10–14 days.
- kill -9 + Redis TTL tests are timing-sensitive; mark them services-required.
- ClickHouse holds port 9000 briefly after SIGTERM — automatic restarts can fail silently.
