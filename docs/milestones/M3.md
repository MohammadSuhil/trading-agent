verdict means nothing.**

## Decisions the owner must make
- If deflated expectancy is not positive: fix the screener (unbounded) or accept it.
- Whether to backfill beyond 2 years: after the 252-session warm-up only ~1 year is testable.

## Known traps
- `run_nightly` rebuilds the full panel each call → quadratic backtest. Optimising it
  must not create a second code path; that is exactly the drift M3 exists to kill.
- Hidden nondeterminism (uuid4 run_id, `datetime.now` defaults, set ordering, polars
  float reduction order) breaks replay and is slow to hunt.
- A Sharpe > 2 on daily Indian equities is a bug (look-ahead, survivorship, split).

## Done when
The anti-drift test passes, `--replay` re-derives a past day, and the gate run's
verdict is recorded with its trial count.
