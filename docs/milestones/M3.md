## Decisions the owner must make
- **Open — the gate has failed.** Out of sample (2021-02 → 2025-07) the frozen control made
  +1.7% in 4.4 years, Sharpe 0.09; 2025-07 → 2026-11 it lost 11.7% (ADR-0004). Deflated
  expectancy is not positive. Fix the screener (unbounded) or accept it — do not stack filters
  on top: the index bear block was tried and made it worse.
- ~~Whether to backfill beyond 2 years~~ **Resolved 2026-11-11:** bars backfilled to 2019-01-01
  (legacy bhavcopy parser), index OHLC to 2019. ~1,400 sessions are testable after warm-up.

## Known traps
- `run_nightly` rebuilds the full panel each call → quadratic backtest. Optimising it
  must not create a second code path; that is exactly the drift M3 exists to kill.
- Hidden nondeterminism (uuid4 run_id, `datetime.now` defaults, set ordering, polars
  float reduction order) breaks replay and is slow to hunt.
- A Sharpe > 2 on daily Indian equities is a bug (look-ahead, survivorship, split).
- **Filter by when a path resolved, not when it started.** Building the barrier library once
  and filtering on start date leaked ~10 sessions of future outcomes (fixed, ADR-0003).
- **Base rates that span "all loaded history" make the result a function of backfill depth**
  (420 → 580 sessions turned 95 trades into 0). Fixed 252-session window (ADR-0003).
- **Survivorship:** members are today's Nifty 500 snapshot applied back to 2019. It flatters
  every arm equally — fine for comparing arms, not for absolute returns.
- **Archive formats drift.** The legacy bhavcopy switched 4→2-digit years on 2020-07-13; some
  2023 index files are month-first. Both are guarded (every row must be dated the requested
  session); see HANDOFF gotcha 7.
- **A lagging regime filter blocks recoveries.** Death-cross BEAR was followed by the *best*
  10-session index returns in 2019–2025 (ADR-0004). Pre-register any new filter and test it OOS.
- **Simulation is a job output, not an API computation** (I-19): the bootstrap runs inside
  `execute_backtest` and lands in `ev.simulation`; it refuses below 750 sessions / 200 trades.

## Done when
The anti-drift test passes, `--replay` re-derives a past day, and the gate run's
verdict is recorded with its trial count.
